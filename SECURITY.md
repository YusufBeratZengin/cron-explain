# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability in `cron-explain`, please do not report it via public GitHub issues.

Instead, please send an email to:
`118852217+YusufBeratZengin@users.noreply.github.com`

Include the following details in your report:
- Type of issue (e.g. Regular Expression Denial of Service / ReDoS, unbounded recursion, buffer overflow)
- Steps to reproduce or proof-of-concept expression
- Potential impact and suggested mitigations if available

You will receive an acknowledgment within 48 hours, followed by updates regarding remediation and security releases.
